# YourFavChoice

A fresh static brand-directory website built from the brand catalogue present in `alhassan069/AJIO`.

## Deploy to Netlify

Publish this folder as the site root. No build command is required.

Suggested Netlify site name:
`yourfavchoice`

The intended URL is:
`https://yourfavchoice.netlify.app/`

## Notes

- `index.html` — page structure
- `styles.css` — responsive visual design
- `app.js` — search and category filtering
- `brands.json` — source brand catalogue used for the page
